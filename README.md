## หลักการ
- 🔬 เขียนจากงานจริงเท่านั้น — ไม่เคยทำสำเร็จ ไม่เอามาเขียน
- 🔒 Public-safe — ไม่มีข้อมูลส่วนตัว ความลับ หรือโทเค็น
- 👤🤖 ทุกขั้นตอนระบุว่าคนทำอะไร AI ทำอะไร
- ♻️ เจอปัญหาใหม่ → เพิ่มบทเรียนเข้าไกด์ทันที

## โครงสร้าง repo
```
index.html          ← หน้าชั้นวาง (bookshelf)
guides/*.html       ← คู่มือแต่ละเล่ม (self-contained, dark theme, Thai)
```
ไกด์ใหม่: สร้าง `guides/<slug>.html` ตามสไตล์เดิม แล้วเพิ่มการ์ดใน `index.html` + อัปเดตตัวเลขสถิติ
