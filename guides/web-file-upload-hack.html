หลอกให้เว็บรับไฟล์ — อัปโหลดผ่านเว็บที่ "ไม่มีปุ่มให้ AI กด"

เว็บสมัยใหม่ซ่อนปุ่มอัปโหลดไว้หลัง input ที่มองไม่เห็น และดักจับการเปลี่ยนไฟล์อย่างซับซ้อน: สูตรจริงที่ใช้ได้ผล — ฉีดไฟล์เข้าหน้าเป็นชิ้นๆ แล้วเรียก React ตรงๆ

🤖 อัปเดต 26 ส.ค. 2026 ⏱️ อ่าน ~10 นาที 🎯 ระดับ: ขั้นกลาง (ต้องมี CDP)

1. ปัญหาที่เจอ 🧭

AI ต้องอัปโหลดไฟล์เข้าเว็บ แต่เว็บทำแบบนี้:

  • ปุ่ม "Upload" ที่เห็นจริงๆ เป็นแค่ตัวเปิด <input type="file"> ที่ซ่อนอยู่ (display:none)
  • framework สมัยใหม่ (React/Vue) ไม่อ่านค่าที่ตั้งผ่าน element.files = ... ตรงๆ
  • บางเว็บลบ input ทิ้งทันทีหลังเลือกไฟล์ → ตั้งค่าไม่ทัน
🚨 บทเรียนข้อ 1: ตั้ง input.files ผ่าน DOM ตรงๆ แล้วเว็บไม่รับเลย — ไม่มี error แต่ไฟล์ไม่เข้า เพราะ React มีระบบติดตามการเปลี่ยนของตัวเอง

2. วิธีที่ลองแล้วไม่เวิร์ก ❌

วิธีผล
input.files = dataTransfer.files ตรงๆเว็บเงียบ — ไม่รับไฟล์
dispatchEvent(new Event('change'))React ไม่เห็นว่าเป็นการเปลี่ยนจริง
ลาก-วางจำลอง (drag-drop) ด้วยไฟล์บางเว็บรับ บางเว็บไม่รับ — ขึ้นกับเว็บ
fetch ไฟล์จากในหน้าแล้วทำ dropเว็บที่บล็อก mixed-content จะไม่ยอม

3. สูตรที่เวิร์ก: 3 ขั้นตอน ⭐

🤖 AI ทำทั้งหมด ผ่านการเชื่อมต่อกับบราวเซอร์ (CDP):

ขั้น 1: ฉีดไฟล์เข้าหน้าเว็บเป็นชิ้นๆ

ไฟล์ใหญ่เกินกว่าจะส่งคำสั่งเดียว → ตัดเป็นชิ้นๆ แล้วประกอบในหน้า:

# ฝั่ง AI: ตัด base64 เป็นชิ้น ~40KB แล้วฉีดทีละชิ้น
js('window.__buB64 = ""')
for chunk in chunks:
    js(f'window.__buB64 += {json.dumps(chunk)}')

# ตรวจว่าครบ
js('window.__buB64.length')   # ต้องเท่ากับต้นฉบับ

ขั้น 2: สร้าง File object + ใส่เข้า input

js("""(() => {
  // แปลง base64 → File
  const bin = atob(window.__buB64);
  const bytes = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
  const blob = new Blob([bytes], {type: 'image/jpeg'});
  const file = new File([blob], 'product.jpg', {type: 'image/jpeg'});

  // ใส่เข้า input ที่ซ่อนอยู่
  const input = document.querySelector('input[type=file]');
  const dt = new DataTransfer();
  dt.items.add(file);
  input.files = dt.files;
})()""")
🚨 บทเรียนข้อ 2: ถ้าเว็บสร้าง input ใหม่ตอนกดปุ่ม "Upload" ต้องหา ตัวที่เพิ่งเกิด — เลือกตัวแรกอาจเป็นตัวเก่าที่เว็บเลิกฟังแล้ว

ขั้น 3: เรียก React ตรงๆ

js("""(() => {
  const input = document.querySelector('input[type=file]');
  // React เก็บ handler ไว้ใน property พิเศษของ element
  const key = Object.keys(input).find(k => k.startsWith('__reactProps'));
  const props = input[key];
  if (props && props.onChange) {
    props.onChange({
      target: input,
      currentTarget: input,
      preventDefault() {},
      stopPropagation() {},
      nativeEvent: new Event('change'),
      persist() {}
    });
    return 'onChange called';
  }
  return 'no handler';
})()""")
✅ เรียก onChange ตรงๆ แบบนี้ = บอก React ว่า "มีการเปลี่ยนไฟล์" เหมือนผู้ใช้เลือกเองจริงๆ — เว็บจะรับไฟล์ทันที

4. เช็กลิสต์ก่อนส่งไฟล์ 📋

💡 ตรวจก่อนเสมอ:
1. ไฟล์มีนามสกุลที่เว็บรับ (ดูจาก accept="..." ของ input)
2. ตั้งชื่อไฟล์ให้ถูก (บางเว็บเช็คชื่อ)
3. ถ้าเว็บต้องการกดปุ่ม "Upload" ก่อน → กดก่อน แล้วค่อยหา input ตัวใหม่

5. บทเรียนของจริง 🛠️

ปัญหาสาเหตุวิธีแก้
เว็บไม่รับไฟล์เลย เงียบๆตั้ง files ตรงๆ โดยไม่แจ้ง Reactเรียก onChange ผ่าน __reactProps ตรงๆ
input หายไปหลังเลือกเว็บลบ input ทิ้งหลังได้ไฟล์ทำทุกอย่างในคำสั่งเดียว ไม่แบ่งหลายรอบ
เลือก input ผิดตัวเว็บมี input หลายตัว (เก่า+ใหม่)หาตัวที่เพิ่งเกิด (ตัวสุดท้าย) เสมอ
ส่งไฟล์ใหญ่แล้วคำสั่งค้างไฟล์ใหญ่เกินส่งคำสั่งเดียวตัดเป็นชิ้น ~40KB แล้วประกอบในหน้า
fetch ไฟล์จากหน้าไม่เข้าเว็บบล็อก mixed-content หรือ CORSใช้วิธีฉีด base64 แทน fetch
