ศูนย์บัญชาการคอนเทนต์: สร้างวิดีโอ + โพสต์ + คิว + ตั้งเวลา จบในระบบเดียว

บทเรียนจากการพัฒนาระบบอัตโนมัติ 5 เวอร์ชันใน 1 วัน: จาก "กดสร้างคลิปทีละตัว" สู่ "สั่งงานทั้งชุดแล้วระบบจัดการเองจนโพสต์ลงโซเชียล"

🤖 AI + Browser Automation 🎬 สร้างวิดีโอ 📲 โพสต์อัตโนมัติ ⏰ ตั้งเวลา

🎯 แนวคิด: "ไอเดียเดียว → คอนเทนต์พร้อมโพสต์"

ระบบคอนเทนต์อัตโนมัติที่ดีไม่ใช่แค่ "สร้างวิดีโอได้" แต่ต้องครอบคลุมทั้งสายงาน ตั้งแต่คิดบทจนถึงโพสต์ลงจริง เราพัฒนาต่อยอดระบบสร้างวิดีโอเดิม (อ่านได้ในไกด์ ทำวิดีโอ UGC ด้วย Google Flow) จนครบวงจร:

ขั้นเดิม (ทำมือ)ใหม่ (ระบบจัดการ)
คิดบทพูดนั่งเขียนเองทุกคลิปเจนบทอัตโนมัติจากข้อมูลสินค้า + เลือกสไตล์
สร้างวิดีโอสั่งทีละตัว รอทีละตัวแถวคิว สั่งหลายงานเรียงกัน รันทีละตัวอัตโนมัติ
เขียนแคปชันคิดใหม่ทุกโพสต์ชุดโพสต์สำเร็จ: แคปชัน + แฮชแท็ก + ลิงก์สินค้า
โพสต์เปิดแอป อัปโหลด พิมพ์เองปุ่มเดียวโพสต์ให้ทั้งคลิปและแคปชัน
จังหวะเวลาต้องอยู่หน้าจอตลอดตั้งเวลาล่วงหน้า โพสต์ช่วงคนดูเยอะแม้อยู่ข้างนอก

🧩 ชิ้นส่วนที่ 1: โหมดสไตล์คอนเทนต์

สินค้าตัวเดียวกันเล่าได้หลายแบบ เราแยก "สไตล์การเล่า" เป็นโหมดที่เลือกได้โหมดเดียวเปลี่ยนทั้งโทนคลิปและชุดแฮชแท็ก:

โหมดเหมาะกับโทน
🛒 คลิปขายของรีวิวตรงๆ โชว์สินค้ากระตือรือร้น เป็นธรรมชาติ
🧺 ปักตะกร้า/นายหน้าแนะนำเหมือนเพื่อนบอกต่อกันเอง ตื่นเต้นเล็กน้อย
📖 เล่าเรื่องรีวิวจากประสบการณ์จริงอบอุ่น น่าเชื่อถือ
🔥 โปรโมชั่นโปรแรง จำกัดเวลาเร่งด่วน พลังสูง

แต่ละโหมดคือ ชุดข้อมูล ที่กำหนด 2 อย่าง: (1) วลีสไตล์ที่ฝังในพรอมต์สร้างวิดีโอ (2) ชุดแฮชแท็กที่ใช้ตอนโพสต์ — เพิ่มโหมดใหม่คือการเพิ่มข้อมูลชุดเดียว ไม่ต้องแก้โค้ดส่วนอื่น

🧩 ชิ้นส่วนที่ 2: เจนบทอัตโนมัติแบบไม่พึ่ง LLM

บทพูดสั้นๆ 8 วินาที (15-20 คำ) ไม่จำเป็นต้องใช้โมเดลภาษาใหญ่ เราใช้ เทมเพลตสุ่ม: เปิดเรื่อง → จุดเด่น → ปิดท้าย แต่ละส่วนมีหลายแบบสุ่มเลือก แล้วประกอบจาก "ชื่อสินค้า + จุดเด่น" ที่กรอกไว้:

💡 เคล็ดลับ: แยกจุดเด่นเป็น 2 กลุ่ม — ภาษาอังกฤษ (สี/ทรง เช่น "olive green wide-leg") ใส่ในพรอมต์ภาพเพื่อให้ AI สร้างสินค้าตรงสี ส่วน ภาษาไทย (เช่น "ใส่สบาย ระบายอากาศดี") เท่านั้นที่เข้าบทพูด ไม่งั้นประโยคไทยจะมีคำอังกฤษปนจนฟังเพี้ยน
  • ตัดความยาวอย่างฉลาด: ถ้าบทเกิน 210 ตัวอักษร (พูดไม่ทันใน 8 วิ) ให้ "ตัดประโยคกลางออก" ไม่ใช่ตัดครึ่งคำ
  • คำอ่านโรมันช่วยได้จริง: สร้างเสียงไทยจากโมเดลที่ไม่ได้ฝึกภาษาไทยโดยเฉพาะ การแนบคำอ่านประกอบทำให้สำเนียงชัดขึ้นมาก (ระวัง: ตัวแปลงบางตัวอักษรไทยหลุดปนมา ต้องกรองออก)
  • อย่าแยกจุดเด่นด้วยเครื่องหมาย - เพราะตัดคำเชื่อม เช่น "wide-leg" จะกลายเป็น "wide" กับ "leg" ใช้ , ; · หรือขึ้นบรรทัดใหม่แทน

🧩 ชิ้นส่วนที่ 3: โพสต์ลงโซเชียลด้วยเบราว์เซอร์ตัวเดิม

ระบบสร้างวิดีโอใช้วิธี "ยืมจอจริง" (ล็อกอินเองหนึ่งครั้ง แล้ว AI คุมผ่านโปรโตคอล CDP) โพสต์ก็ใช้สูตรเดียวกัน:

  1. คนล็อกอินเองครั้งเดียวผ่านหน้าจอเครื่อง — ระบบไม่เก็บรหัสผ่านเด็ดขาด
  2. AI เปิดหน้าอัปโหลด → ฉีดไฟล์วิดีโอเข้า input[type=file] ที่ซ่อนอยู่ (สูตรเดียวกับไกด์ หลอกให้เว็บรับไฟล์)
  3. รอช่องแคปชันพร้อม → พิมพ์แคปชันให้ → กดปุ่มโพสต์
  4. ตรวจผลลัพธ์: สำเร็จ / เตรียมดราฟต์ไว้ให้ตรวจ / กดแล้วแต่ยืนยันไม่ได้ (ให้คนเช็กในแอป)
⚠️ โหมดดราฟต์สำคัญมาก: ก่อนปล่อยให้โพสต์จริงทุกครั้ง ควรทดสอบแบบ "เตรียมทุกอย่างให้พร้อมแต่ไม่กดโพสต์" ก่อน — เว็บแต่ละเจ้าเปลี่ยนหน้าตาบ่อย เซเลกเตอร์เดิมอาจหาปุ่มไม่เจอ โหมดดราฟต์ทำให้รู้ตัวก่อนพลาดโพสต์จริง

🧩 ชิ้นส่วนที่ 4: แถวคิว + ตั้งเวลา

ข้อจำกัดของระบบที่ใช้เบราว์เซอร์ตัวเดียวคือ ทำได้ทีละงาน แต่ไม่ต้องให้คนนั่งรอ — ใช้แถวคิว:

  • คิวงาน: รับงานใหม่ได้ตลอดแม้มีงานรันอยู่ เธรดตัวเดียววนตรวจทุก 3 วินาที ปล่อยงานถัดไปเมื่อเครื่องว่าง สูงสุด 10 งานรอคิว
  • สถานะรอดรีสตาร์ท: คิวเก็บลงไฟล์ งานที่ "กำลังรัน" ตอนเครื่องดับถูกตีตราว่าล้มเหลวให้กดใหม่ (ไม่ปล่อยผี)
  • ตั้งเวลาโพสต์: เลือกว่าจะโพสต์กี่โมง ระบบเข้าคิวให้อัตโนมัติเมื่อถึงเวลา — แนะนำช่วงคนดูเยอะ: 07:00 / 12:00 / 19:00
  • กันชน: คิวต้องตรวจทั้ง "งานสร้าง" และ "งานโพสต์" ว่าว่างจริงก่อนปล่อยงานถัดไป ไม่งั้นสองงานจะแย่งเมาส์/คีย์บอร์ดกัน

🔐 เช็กลิสต์ความปลอดภัยก่อนเปิดระบบออกอินเทอร์เน็ต

ระบบนี้เปิดให้เข้าถึงจากนอกบ้านผ่านอุโมงค์ (Cloudflare Tunnel) สิ่งที่ต้องทำก่อนเปิด:

  • ✅ ล็อกอินก่อนเข้า: ใช้คุกกี้เซสชัน (HttpOnly) ไม่เก็บโทเค็นใน JavaScript ของเบราว์เซอร์ + จำกัดความถี่การล็อกอินผิด
  • ✅ ล็อกไฟล์มีเดียด้วย: วิดีโอและรูปสินค้าต้องผ่านด่านล็อกอินเหมือนกัน (ข้อพลาดยอดฮิต: ล็อกเฉพาะ API แต่ลืมล็อกไฟล์ตรง)
  • ✅ ห้ามฝังโทเค็นในโค้ด: ค่าลับอยู่ในไฟล์ตั้งค่าที่จำกัดสิทธิ์เท่านั้น ถ้าไม่มีค่าให้ระบบปฏิเสธการทำงานไปเลย
  • ✅ ก่อนขึ้น GitHub: สแกนค่าลับในโค้ดทุกครั้ง + กันไฟล์ข้อมูล (ประวัติผู้ใช้, เซสชัน, ไฟล์วิดีโอ) เข้า repo ด้วย .gitignore
  • ✅ กันเส้นทางย้อน: ชื่อไฟล์ที่รับจากผู้ใช้ต้องห้ามมี .. หรือ / ไม่งั้นอ่านไฟล์นอกระบบได้

📋 สรุป: ลำดับการพัฒนาระบบ 5 เวอร์ชัน

เวอร์ชันสิ่งที่เพิ่มบทเรียนสำคัญ
v1.0สร้างวิดีโอจากบท + รูปสินค้าต้องบอกสี/ทรงสินค้าในพรอมต์ ไม่งั้น AI เดาเอง (เคยได้กางเกงผิดสี)
v1.1หลายฉากต่อคลิปเดียวประวัติงานต้องอัปเดตตอน "จบ" ไม่ใช่แค่ตอน "เริ่ม"
v1.2ล็อกอิน + กันไฟล์มีเดียล็อกไฟล์ตรงสำคัญเท่าล็อก API
v1.34 โหมด + เจนบท + ชุดโพสต์เจนบทแบบเทมเพลตพอสำหรับงานสั้น ไม่ต้องใช้ LLM
v1.4โพสต์โซเชียลอัตโนมัติต้องมีโหมดดราฟต์ก่อนโพสต์จริงเสมอ
v1.5แถวคิว + ตั้งเวลาคิวรอดรีสตาร์ท + กันชนต้องตรวจงานทุกประเภท
✅ หลักการที่ได้ทั้งชุด: (1) คนทำขั้นตอนที่ต้องใช้ "ตัวตน" ครั้งเดียว (ล็อกอิน) ที่เหลือ AI ทำซ้ำให้ (2) ทุกการกระทำที่ย้อนกลับไม่ได้ (โพสต์จริง ใช้จ่ายเครดิต) ต้องมีการยืนยัน + โหมดทดสอบก่อนเสมอ (3) ความลับไม่อยู่ในโค้ด ไม่อยู่ในเบราว์เซอร์ และไม่อยู่ใน repo สาธารณะ
