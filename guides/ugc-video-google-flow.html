2. สิ่งที่ต้องเตรียม 🔧

👤 คนทำครั้งเดียวตอนตั้งระบบ:

  • บัญชี Google ที่มีสิทธิ์ใช้ Flow (AI Pro/Ultra) ล็อกอินใน Chrome ให้เรียบร้อย
  • เปิด Chrome พร้อม --remote-debugging-port=9222 (ให้ AI เชื่อมต่อควบคุมได้)

🤖 AI ทำตรวจสอบความพร้อมก่อนเริ่มงานทุกครั้ง:

# ตรวจว่า Chrome เปิด CDP อยู่
curl -s http://127.0.0.1:9222/json | head -5
💡 สคริปต์ CDP ทั้งหมดต้องใช้ Python ที่ลง websockets ไว้แล้วเท่านั้น — ถ้าใช้ Python ตัวอื่นจะเจอ ModuleNotFoundError (บทเรียนจริงข้อ 1)

3. ขั้นตอนสร้างวิดีโอ (Workflow จริง) 🎥

ขั้น 1: เตรียมรูปสินค้า 👤→🤖

คนส่งรูปสินค้าในแชท → AI คัดลอกไปไว้ในโฟลเดอร์ที่ Chrome อ่านได้ (ตรวจสอบสิทธิ์ไฟล์ด้วย chmod 644 เสมอ)

ขั้น 2: ตรวจว่าอยู่หน้าพร้อมสร้าง

หน้าจอที่พร้อมต้องมี: ช่องพิมพ์เขียนว่า "What do you want to create?" + ชิป Video · 720p · 8s

🚨 ถ้าเห็น "What do you want to change?" = หลุดเข้า image editor ผิดหน้า ให้ย้อนกลับหน้าโปรเจกต์ก่อนเสมอ

ขั้น 3: อัปโหลดรูปใหม่เข้า Flow ⭐ (จุดที่พลาดบ่อยสุด)

กฎเหล็ก: อัปโหลดรูปใหม่ทุกครั้ง และเลือกเฉพาะรูปที่เพิ่งอัปโหลดเท่านั้น

  1. กดปุ่ม + ในแถบคอมโพสเซอร์ → เปิดหน้าต่างเลือกสื่อ (asset picker)
  2. กดปุ่ม Upload media
  3. Flow จะสร้าง input[type=file] ตัวใหม่ → ส่งไฟล์เข้า ตัวสุดท้าย (ตัวที่เพิ่งเกิด)
  4. รอรูปใหม่ปรากฏเป็น thumbnail → คลิกเฉพาะรูปที่เพิ่งอัปโหลด
🚨 บทเรียนจริงข้อ 2: ถ้าเผลอใช้รูปเก่าค้างใน library แทนรูปใหม่ วิดีโอจะสร้างโดยไม่ยึดรูปสินค้าของเรา → สินค้าเพี้ยนทั้งคลิป เคยเจอมาแล้วและต้องสร้างใหม่เสียเครดิตฟรี
🚨 บทเรียนจริงข้อ 3: ใน asset picker ให้คลิก "แถวรายการด้านขวา" — คลิกรูปย่อฝั่งซ้ายจะเปิดหน้าแก้ไขแทนการแนบ

ขั้น 4: ตรวจโมเดล (Omni Flash)

คลิกชิป Video · 720p · 8s → เมนูเลือกโมเดลเด้งขึ้น → ตรวจว่าเลือก Omni Flash อยู่ (เช็กเครดิตจากป้ายแพ็กเกจมุมขวาบน)

ขั้น 5: ใส่พรอมต์แล้วส่ง

โฟกัสช่องพิมพ์ → ใส่พรอมต์ด้วย input events จริง (keydown/keypress/keyup ครบ 3 จังหวะ ไม่งั้น React ไม่รับค่า) → กด Enter → รอ ~3–4 นาที → ดาวน์โหลดจากการ์ดในกริด "All Media"

4. สูตรเขียนพรอมต์ที่ได้ผล ✅

1. ฟอร์แมต     → "9:16 vertical, 8 seconds, UGC TikTok seller video,
                   ONE continuous full-body shot"
2. คน+ฉาก      → ระบุให้ตรงกับรูปอ้างอิง "from the attached reference photo"
3. บทพูดไทย    → ใส่คำพูดจริง + สั่ง "EXACTLY ONCE, NO repetition"
4. จังหวะท่าทาง → ผูกแต่ละวลีกับท่า ("ขณะพูด X ให้ทำท่า Y")
5. ช่วงเวลา    → พูดวิที่ 1–6 แล้วเงียบยิ้มปิดท้าย
6. ล็อกสินค้า   → "CRITICAL: exact product from reference photo —
                   ระบุสี ทรง ดีเทล — do not morph or warp"
7. ห้ามตัวหนังสือ → "ABSOLUTELY NO text, NO subtitles overlaid"

กฎการพูด (สำคัญมาก)

  • ✅ สั่ง fluent natural conversational Thai, normal speaking speed → เสียงเป็นธรรมชาติ
  • ❌ ห้ามสั่ง "slowly, syllable by syllable" → เสียงจะกลายเป็นหุ่นยนต์
  • ✅ ถ้ามีคำที่โมเดลชอบพูดซ้ำ ให้สั่งชัด: the phrase 'X' must be spoken EXACTLY ONE TIME
  • ❌ บทพูดอย่ายาวเกิน 8 วินาที → พูดไม่จบหรือพูดซ้ำ

5. ระบบตรวจคุณภาพ 4 ด่าน 🔍

🤖 AI ทำครบทุกด่าน ทุกคลิป ก่อนส่งให้คน:

ด่านเครื่องมือผ่านเมื่อ
1. สเปกไฟล์ffprobeh264+aac, 720×1280, 8.0 วิ
2. เสียงพูดWhisper (ASR)คำพูดตรงบท + ไม่มีคำซ้ำ
3. ภาพ/เฟรมffmpeg grid + vision modelสินค้าตรงรูปอ้างอิง ไม่ morph คนสม่ำเสมอ
4. ตัวหนังสือตรวจในเฟรมเดียวกันไม่มีซับ/ตัวอักษรเพี้ยนทับวิดีโอ
# ด่าน 1: สเปก
ffprobe -v error -show_entries format=duration \
  -show_entries stream=codec_name,width,height -of csv=p=0 video.mp4

# ด่าน 2: ดึงเสียงไปทำ ASR
ffmpeg -y -i video.mp4 -ar 16000 -ac 1 audio.wav

# ด่าน 3: ทำเฟรม grid 2x2 ให้ vision model ตรวจ
ffmpeg -y -i video.mp4 -vf "select='eq(n\,25)+eq(n\,85)+eq(n\,140)+eq(n\,190)',\
  scale=360:-1,tile=2x2" -frames:v 1 grid.jpg
💡 ASR โมเดลเล็กฟังไทยเพี้ยนบ้าง (เช่น "ไม่อึดอัด" → "ไม่ออกอับ") ให้อ่านจับความ + นับจำนวนครั้งที่คำสำคัญปรากฏแทนการเทียบตัวอักษรตรง ๆ

6. ตารางบทเรียนของจริง 10 ข้อ 🛠️

ปัญหาสาเหตุวิธีแก้
สินค้าในวิดีโอไม่ตรงรูปใช้รูปเก่าค้างใน pickerอัปโหลดรูปใหม่เสมอ + คลิกเฉพาะ thumbnail ของรูปใหม่
พูดซ้ำคำเดิม 2 ครั้งโมเดลชอบย้ำคำสั่ง "spoken EXACTLY ONE TIME" แล้วตรวจด้วย ASR
อัปโหลดเงียบ ไม่เข้าตั้งไฟล์กับ input ตัวเก่าใช้ input[type=file] ตัวสุดท้ายที่เพิ่งเกิด
คลิกแนบรูปแล้วเปิดหน้าแก้ไขคลิกถูกฝั่งของ pickerคลิกแถวรายการด้านขวา ไม่ใช่รูปย่อฝั่งซ้าย
ปุ่มตั้งค่าโมเดลหาไม่เจอFlow เปลี่ยน UIใช้ชิป Video · 720p · 8s แทนปุ่ม Settings เก่า
เว็บไม่รับข้อความที่พิมพ์พิมพ์ผ่าน DOM ตรง ๆใช้ input events จริง (keydown/keypress/keyup)
เสียงหุ่นยนต์ ฟังช้าสั่ง "slowly, clearly"สั่ง "normal speaking speed, like a real seller"
สินค้า morph/ยืด/เปลี่ยนรูปมีท่าดึง/เปิดสินค้าในคลิปสั่ง "ONE static shot, hold product STEADILY"
ซับไตเติ้ลไทยเพี้ยนติดจอโมเดลเขียนไทยไม่เก่งสั่งห้ามตัวหนังสือ ถ้าอยากได้ซับค่อยใส่เองภายหลัง
คลิปดูช้า เพลินเกินไป ไม่เหมือน TikTokAI สร้างจังหวะช้าละมุนตัดช็อตสั้น ~1.2 วิ + เร่ง B-roll ~1.5x ( ffmpeg )
