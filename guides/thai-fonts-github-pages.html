ภาษาไทยกลายเป็น "ตัวต่างดาว" บนเว็บสาธารณะ
— ไล่สาเหตุเป็นชั้น และแก้แบบถาวร

เว็บที่เพิ่งขึ้นออนไลน์แสดงไทยเป็นกล่อง □ ทั้งหน้า ทั้งที่โค้ดไม่มีอะไรผิด: สูตรวินิจฉัย 3 ชั้น และวิธีแก้ที่ฝังฟอนต์ไทยไว้ในเว็บตัวเอง ไม่ต้องพึ่งบริการภายนอกอีกเลย

🤖 อัปเดต 26 ส.ค. 2026 ⏱️ อ่าน ~8 นาที 🎯 ระดับ: ทำตามได้เลย

1. อาการที่เห็น 👀

เปิดเว็บที่เราเพิ่ง deploy ขึ้นบริการโฮสต์เว็บฟรี (เช่น username.github.io) แล้วภาษาไทยกลายเป็นกล่องสี่เหลี่ยมหรือสัญลักษณ์เพี้ยนอ่านไม่ออก — "ตัวหนังสือต่างดาว"

ที่ตรวจแล้วผล
Encoding ของไฟล์UTF-8 ถูกต้อง (ไม่ใช่ปัญหา)
เนื้อหาในโค้ดภาษาไทยปกติ ดูในซอร์สได้
ฟอนต์ในเครื่องเครื่องมีฟอนต์ไทยครบ
🚨 อย่าเพิ่งเปลี่ยนโค้ดสุ่มๆ — ปัญหานี้ 90% อยู่ที่ "ฟอนต์" ไม่ใช่เนื้อหา หรือ encoding

2. ไล่สาเหตุเป็น 3 ชั้น 🔍

🤖 AI ทำวิเคราะห์ไล่จากบนลงล่าง — แต่ละชั้นมีวิธีเช็กของตัวเอง:

ชั้นที่ 1: อ้างฟอนต์ที่ไม่มีอยู่จริง

CSS เขียน font-family: 'Sarabun' ไว้ แต่ไม่เคยโหลดฟอนต์นั้นเข้ามา → เบราว์เซอร์หาไม่เจอ ก็วาดตัวหนังสือไม่ได้

# เช็ก: ใน CSS มี @font-face หรือ @import ที่โหลดฟอนต์นั้นจริงไหม
grep -n "font-face\|@import" assets/css/*.css

ชั้นที่ 2: โหลดฟอนต์จากบริการนอกไม่ได้ (เงียบ!)

เพิ่ม @import url('https://fonts.googleapis.com/...') แล้วคิดว่าจบ — ปรากฏว่าเครือข่ายนั้นเข้าบริการฟอนต์นอกไม่ได้ ผลคือ ไม่มี error ใดๆ แต่ฟอนต์ไม่มา

# เช็กจากเครื่อง: ดึงได้ด้วยไหม
curl -s -o /dev/null -w "%{http_code}" "https://fonts.googleapis.com/css2?family=Sarabun&display=swap"

# เช็กจากบราวเซอร์จริง (สำคัญกว่า!) ผ่าน DevTools/CDP:
document.fonts.size          # 0 = ไม่มีเว็บฟอนต์โหลดเลย
🚨 กับดัก: document.fonts.check('16px Sarabun') ตอบ true ได้แม้ฟอนต์ยังไม่โหลด — เพราะมันตรวจว่า "ถ้าจะใช้ฟอนต์นี้ วาดได้ไหม" ซึ่งเบราว์เซอร์นับฟอนต์ fallback ด้วย อย่าใช้เป็นตัวตัดสิน

ชั้นที่ 3: เบราว์เซอร์/โปรไฟล์ไม่มีฟอนต์ไทยสำรอง

ถ้าสองชั้นแรกผ่านแต่ยังเพี้ยน เช็กว่าเบราว์เซอร์ตัวนั้นมองเห็นฟอนต์ไทยของระบบหรือไม่:

fc-list :lang=th | head -5    # ต้องมีอย่างน้อย 1 ตัว (เช่น Noto Sans Thai)

3. วิธีแก้แบบถาวร: ฝังฟอนต์ไทยไว้ในเว็บเอง ✅

👤 คนทำแค่ดูผลลัพธ์สุดท้าย · 🤖 AI ทำทุกขั้นตอน:

ขั้น 1: ดึง "subset ไทย" ของฟอนต์มา (เล็กมาก ~10 KB)

บริการฟอนต์แยกไฟล์ตามช่วงอักษร — เฉพาะส่วนไทยน้ำหนักละไม่ถึง 10 KB:

# ⚠️ ต้องใส่ User-Agent เป็นเบราว์เซอร์จริง ไม่งั้นจะได้ไฟล์ TTF ตัวเต็มใหญ่ๆ แทน
UA="Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 \
    (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36"

curl -s -H "User-Agent: $UA" \
  "https://fonts.googleapis.com/css2?family=Sarabun:wght@400&display=swap"
# ใน CSS ที่ได้ หาบล็อก /* thai */ แล้วคัดลอก URL .woff2 ออกมา
# ดาวน์โหลดเก็บไว้ในเว็บ: assets/fonts/sarabun-400-thai.woff2

ขั้น 2: ประกาศ @font-face ชี้ไฟล์ในเว็บ

@font-face {
  font-family: 'Sarabun';
  font-style: normal;
  font-weight: 400;
  font-display: swap;                     /* แสดงฟอนต์ระบบก่อน ระหว่างโหลด */
  src: url('../fonts/sarabun-400-thai.woff2') format('woff2');
  unicode-range: U+0E01-0E5B, U+200C-200D, U+25CC;  /* โหลดเฉพาะเมื่อเจอไทย */
}
💡 unicode-range ทำให้เบราว์เซอร์ดาวน์โหลดไฟล์นี้เฉพาะเมื่อหน้ามีอักษรไทยจริงๆ — หน้าภาษาอังกฤษไม่เสียแบนด์วิดท์เลย

ขั้น 3: เผยแพร่แล้วตรวจ

# ไฟล์ฟอนต์ต้องเข้าถึงได้
curl -s -o /dev/null -w "%{http_code}" \
  https://username.github.io/assets/fonts/sarabun-400-thai.woff2   # ต้อง 200

# ในบราวเซอร์ (DevTools console) — ตรวจว่าโหลดจริง
document.fonts.load('400 20px Sarabun', 'ทดสอบภาษาไทย')
  .then(f => console.log(f.length))   // ได้ 1 = สำเร็จ

4. ผลลัพธ์ที่ได้ 🎯

✅ เว็บแสดงไทยถูกต้อง 100% — ตรวจผ่าน document.fonts: ฟอนต์โหลดครบทั้งสองน้ำหนัก
✅ ไม่พึ่งเซิร์ฟเวอร์ภายนอกเลย → เว็บเร็วขึ้น (ลด 1 การเรียกข้ามโดเมน) และไม่มีวันพังเพราะบริการฟอนต์ล่ม/ถูกบล็อค
✅ ไฟล์เล็ก: ฟอนต์ไทย subset รวม ~20 KB สำหรับ 2 น้ำหนัก

5. บทเรียนของจริง 🛠️

ปัญหาสาเหตุวิธีแก้
ไทยเป็นกล่องทั้งหน้าอ้างฟอนต์ใน CSS แต่ไม่ได้โหลดเข้ามาต้องมี @font-face หรือ @import ที่ชี้แหล่งฟอนต์จริง
@import แล้วแต่ยังเพี้ยนเครือข่ายบล็อคบริการฟอนต์นอก — ล้มเหลวแบบเงียบตรวจ document.fonts.size ในบราวเซอร์จริง ไม่ใช่แค่โค้ด
ตรวจ fonts.check() ผ่านแต่ฟอนต์ไม่มาcheck() นับฟอนต์ fallback ด้วยใช้ fonts.load() แล้วดูจำนวน/สถานะแทน
ดึงไฟล์จากบริการฟอนต์ได้แต่ใหญ่ผิดปกติไม่ได้ส่ง User-Agent ของเบราว์เซอร์ใส่ UA เป็น Chrome จริง จะได้ subset woff2 ตัวเล็ก
อยากได้ความเสถียรระยะยาวพึ่ง CDN ภายนอก = พังได้เมื่อไหร่ก็ได้ฝังไฟล์ฟอนต์ในเว็บเอง (วิธีในไกด์นี้)
